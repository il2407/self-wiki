# Agent Instructions

Read and follow `WIKI_RULES.md` before working in this repository.

The repository is a personal, multi-domain LLM wiki. Treat `raw/` as immutable
source material and `wiki/` as derived knowledge. Never modify or delete a raw
source. Do not edit the wiki during ingestion until the user has approved a
written update plan.

When the user asks a question without explicitly requesting a wiki update,
answer the question without changing files.
