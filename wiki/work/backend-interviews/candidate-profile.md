## Humanz Ads

עידו אישר שהמערכת הייתה greenfield: לא הייתה מערכת קודמת, והוא וה־CTO בנו
את התשתית מאפס. עידו היה אחראי על תכנון הארכיטקטורה ועל כתיבת הקוד, בשיתוף
ה־CTO. אין להסיק מכך שעבד לבד או שכתב אישית כל רכיב בגרסה הסופית.
`[Source: raw/work/backend-interviews/humanz-ads/2026-08-22/reconstruction-session-01.md, User statement and Faithful interpretation]`

קורות החיים מייחסים לעידו גם הובלת אינטגרציות Meta Ads, מערכות event-driven,
analytics, financial reporting, monitoring, RAG ותהליכי חקירה מבוססי AI.
הטענות המספריות על זמני יצירה, אישורים וצמיחת הכנסות טרם קיבלו מקור נוסף או
הסבר מדידה. `[Source: raw/work/backend-interviews/profile/2026-08-22-ido-lev-cv.pdf, page 1, Hands-on Backend Tech Lead - Humanz Ads]`

## Stack מתועד

- שפות: Java, Python, TypeScript.
- Backend: Spring Boot, FastAPI, Node.js, Kafka, Redis Streams/PubSub.
- Cloud ותשתיות: AWS Lambda, SQS, SNS, EventBridge, S3, Docker ו־Kubernetes.
- נתונים ו־observability: PostgreSQL, MongoDB, Elasticsearch, Kibana ו־CloudWatch.
- AI: OpenAI API, RAG, embeddings, vector search, guardrails ו־agentic workflows.
