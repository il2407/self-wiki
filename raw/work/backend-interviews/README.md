# מקורות ללמידת Backend

יש לשמור כאן חומרי מקור שמהם נלמד ידע מקצועי, לדוגמה:

- מאמרים ותיעוד טכני;
- פרקים מספרים וקורסים, בכפוף לזכויות השימוש;
- הערות אישיות מלמידה או מניסיון מקצועי;
- קוד לדוגמה וניסויים;
- שאלות ותשובות מקצועיות;
- תיאורי משרות ומדריכי ריאיון, כאשר הם רלוונטיים.

לא שומרים כאן סיסמאות, פרטי גישה, קוד מקור קנייני, מידע אישי של לקוחות או מידע
אישי של מראיינים. חומר פנימי של מעסיק יישמר רק בריפו פרטי, לאחר אישור מפורש
שהמשתמש רשאי להחזיק בו ותיעוד האישור לצד המקור.
